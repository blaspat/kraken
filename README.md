# Kraken

Pirate Bay search and download UI.

## Features

- Search The Pirate Bay
- Download torrents
- Web-based UI

## Installation

```bash
# Clone the repo
git clone https://github.com/blaspat/kraken.git
cd kraken

# Install dependencies
pip3 install -r requirements.txt
```

## Usage

```bash
python3 app.py
```

## Access

- **URL:** http://127.0.0.1:5000
